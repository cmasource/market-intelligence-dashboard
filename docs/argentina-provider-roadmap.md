# Argentina Provider Roadmap

## BYMA

BYMA is the primary future path for official local market quotes and instrument data. Integration may require access conditions, commercial agreements, technical homologation or licensed market-data products.

## CNV

CNV is a future public-source path for company filings, relevant facts, issuers and fundamentals. It is not positioned as a live intraday quote provider in this sprint.

## Brokers and Licensed Providers

IOL, PPI or other broker/API providers can be considered only through authorized APIs or licensed data agreements. The platform should not scrape broker websites or rely on unauthorized private endpoints.

## Current Safe Step

Sprint 20 adds a manual validated-load path and normalized Argentina registry so real local values can replace selected mock prices without editing many UI components.
